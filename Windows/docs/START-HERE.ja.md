# thermal kun Windows 0.1.4

## 導入と更新

1. [配布フォルダー](https://github.com/Kohei-SAWADA/thermal_kun/releases/tag/windows-v0.1.4-temperature-preview)から `thermal-kun-windows-0.1.4-temperature-preview-x64.zip` と同名の `.sha256` を取得します。
2. PowerShellの `Get-FileHash` でZIPのSHA-256を照合します。
3. ZIPをすべて展開し、`ThermalKun/ThermalKun.exe` を起動します。.NETランタイムは同梱しています。
4. CPU温度を使う場合は設定の「CPU温度を有効にする / 再接続」を選び、導入確認とWindowsの管理者確認を本人が承認します。

既にPawnIO 2.2以降がある場合、ドライバーの再導入は不要です。温度取得用の管理者確認はアプリ起動ごとに必要です。画面は通常権限で動きます。確認をキャンセルしてもCPU/GPU使用率とメモリ使用量は利用できます。

別の監視アプリやHTTPサーバーの設定は不要です。CPU以外の温度や推定値でCPU温度を埋めません。欠測・古い温度はUnavailableになります。

更新するときは設定の「thermal kunを終了」またはトレイのQuitで終了し、同じ場所へZIP全体を展開します。設定は `%LOCALAPPDATA%/ThermalKun` にあり、保持されます。展開途中のEXEだけをコピーしないでください。

## 0.1.4の変更

MEMORY横のメモリ圧力表示「Unsupported」を、詳細・コンパクト画面から削除しました。ツールチップと設定のセンサー一覧にもメモリ圧力を表示しません。メモリ使用量のGiB値とバーは引き続き表示・更新します。

## 0.1.3までの変更

Windows版のTHERMAL STATUS欄を詳細・コンパクト画面、設定のセンサー一覧から削除しました。履歴を02に繰り上げ、空いた高さを履歴グラフに使います。温度取得中の終了処理と二重起動時の再表示には0.1.2の修正を含みます。

## 操作

| 操作 | 方法 |
|---|---|
| コンパクト／詳細 | 右上の切替、またはCtrl+C |
| 設定・ライト／ダーク | 右上の設定、またはCtrl+, |
| 非表示 | 右上の－、またはEscape |
| 再表示 | トレイをダブルクリック、右クリック→Show、または同じEXEを再実行 |
| 終了 | 設定の「thermal kunを終了」、またはトレイのQuit |
| 温度の停止 | 設定の「温度取得を停止」 |
| 履歴 | 詳細画面。ポインターで過去の値を表示。RESETはピークだけをリセット |

自動起動は初期状態OFFです。設定で本人が明示的に選ぶ場合だけ登録します。

## 制限と削除

開発プレビューです。今回の検証機はWindows 11 Home x64 / Intel Core i5-8250Uです。他PC、ARM64、複数画面、別DPI、スリープ復帰、外部測定器による温度校正、公開配布時のSmartScreen評価は未検証です。未対応の熱状態・メモリ圧力は診断データの互換性のため内部に保持しますが、画面には表示しません。

削除はアプリを終了して展開フォルダーを削除します。設定・ログを残すかは本人が選べます。PawnIOはPCに残るため、不要な場合はWindowsの「インストールされているアプリ」から本人が削除します。
